# Contributing

Describe the user-visible problem, expected behavior and affected platform before a large change. Include reproduction steps and sanitized logs in an issue.

Keep changes scoped to the plugin, installers and release tooling. Lux3D MCP changes belong in its independent repository. Coohom hosted applications, model services and editor internals are outside this repository's source scope.

Follow [development and test instructions](docs/development.md). Include relevant test results and document platform limitations in a pull request. Do not change the selected registry, runtime contract or installation side effects without explaining the compatibility impact.

Use only assets you have permission to share. This project uses the [MIT License](LICENSE); third-party components retain their own terms.

The maintained development source is in GitLab. This GitHub repository receives reviewed source exports. Open issues or pull requests here; maintainers must apply accepted changes to the development source before the next export so contributions are preserved.
